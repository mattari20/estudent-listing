# Virtual University delivery-mode and campus ambiguity

Date checked: 2026-10-26

## Official source

Virtual University's official Punjab campus directory lists multiple own campuses and private campuses across Punjab, including multiple Lahore locations:
https://www.vu.edu.pk/PVCs/Default?p=punjab

Programme sources in the evidence register:
- Programme ID 7, BS Computer Science: https://vu.edu.pk/AboutUs/ProgramDetails?StudyProgramID=4
- Programme ID 55, BS Biotechnology: https://vu.edu.pk/AboutUs/ProgramsOffered?Degree=BS

## Interpretation

The presence of multiple VU campuses means the institution-wide online/virtual delivery model cannot establish that a programme belongs to a particular Lahore campus record. A virtual learning model and a physical support/examination campus are separate attributes and should not be conflated.

## Required evidence

1. Determine whether the canonical record is intended to represent the university-level online programme or a physical campus-specific offering.
2. If campus-specific, obtain an official programme source that explicitly associates the programme with that campus, or official confirmation of the intended campus relationship.
3. Preserve delivery mode separately from campus identity.
4. Keep programme IDs 7 and 55 in review until the model and relationship are clear.

This is a documentation-only note. It does not authorize any production database changes.
