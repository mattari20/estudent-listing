# DEV-025 — Admissions and Eligibility Public Integration

Status: Implemented

## Scope
Connect governed Admission Intake and Eligibility data to public institution/program profiles.

## Implemented
- Program offerings load admission intakes.
- Admission intakes load eligibility rules.
- Cancelled and suspended intakes are excluded from the public profile.
- Application dates, status and official application destination are displayed when available.
- Eligibility is presented as information tied to a specific intake, not as a universal program claim.

## Governance boundary
Eligibility is not treated as merit, selection outcome or enrollment. Missing eligibility information remains an availability state rather than proof of ineligibility.
