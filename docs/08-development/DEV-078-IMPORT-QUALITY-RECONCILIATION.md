# DEV-078 — Import Data Quality and Reconciliation Intelligence
Document ID: DEV-078
Status: Implemented

Adds batch-level descriptive quality indicators: total rows, invalid rows, candidates, promoted rows, rejected rows, open conflicts and rates.

These are operational reconciliation indicators, not a universal trust score and not a ranking of institutions. Missing optional data remains distinct from invalid data, and quality reports remain traceable to batch rows and conflict records.
