# DEV-028 — Search and Filter Integration

Status: Implemented

## Implemented
- Search covers institution names, official names, short names and governed aliases.
- Search can discover institutions through active program name, discipline or level.
- Search can discover institutions through campus city.
- Filters support institution type, city and program/discipline.
- Pagination preserves query and filter parameters.

## Boundary
Search is discovery, not a quality ranking. Alphabetical ordering is retained until an approved relevance methodology exists.
